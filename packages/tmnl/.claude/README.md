# .claude/

Agent workspace for Val (Claude Code persona).

## Structure

| Directory | Purpose |
|-----------|---------|
| [`logs/`](logs/README.md) | Reflection logs — successes, failures, learnings |
| [`plans/`](plans/README.md) | Implementation plans awaiting approval |
| [`context/`](context/README.md) | Session context snapshots for recovery |

## Usage

This directory is gitignored by default. Contents are ephemeral per-session unless explicitly committed.
