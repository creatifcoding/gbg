The session is a tree, not a flat log. Messages form branches via parentId. Compaction summarizes old context without destroying it. Branching enables exploration. Labels bookmark interesting points. This is the model from pi, DAWs, and event sourcing — converged.

Core Primitives

🌳 Session Tree

Append-only tree with parentId. Branching is first-class. Nothing is ever deleted.

pi · DAW · Event Sourcing

👆 Leaf Pointer

Mutable cursor to current tip. branch(entryId) moves it. New entries grow from leaf.

pi SessionManager

📦 Compaction

Summarize old entries → CompactionEntry. Preserves full history, manages context window.

pi · Event Sourcing snapshots

🔮 Context Projection

buildContext(leafId) — walk tree, apply compaction, emit messages. The LLM's view.

pi · CQRS read models

🏷️ Entry Type Union

Schema.TaggedStruct discriminated union. Extensible: message, compaction, branch_summary, custom, label...

pi · Effect Schema

🪪 Session Identity

TmnlSessionId wrapping PiSessionId. Separate ID spaces with explicit mapping table.

Split authority decision
Lifecycle Primitives

✨ Create

New session with config. Generate IDs, initial header, first leaf. Persist to cold tier.

pi · Effect.Service

▶️ Resume

Load from persistence, rebuild in-memory index (byId map), set leafId, hydrate atoms.

pi · pi-web-ui

🌿 Branch

Move leafId to earlier entry. New entries grow new branch. Old branch preserved. Summary optional.

pi · DAW · Multi-Agent

🍴 Fork

Extract root→entry path into new session file. Independent copy. Used for agent spawning.

pi · Multi-Agent fan-out

📐 Compact

Find cut point, summarize old messages via LLM, append CompactionEntry, keep recent.

pi auto-compaction

🗑️ Dispose

Release resources via Effect.Scope finalizer. Close subscriptions. Flush warm→cold.
