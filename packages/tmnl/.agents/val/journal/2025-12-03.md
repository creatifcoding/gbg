# 2025-12-03 — Component Deduplication Sprint

## Context

Morph edits introduced JSX syntax errors (missing `>` after `style={{...}}`) and duplicate component declarations across testbed files. Prime chose:
- **Interface strategy**: Extend shared components to support all variants
- **Cleanup strategy**: Surgical per-file removal

## Changes

### TestCard Extended (`shared/primitives.tsx`)

```tsx
interface TestCardProps {
  title?: string      // Original
  label?: string      // Alias (from DataGridTestbed)
  description?: string
  actions?: ReactNode // New slot
  children: ReactNode
  variant?: 'full' | 'compact'  // New
}
```

- `variant="full"` (default): Bordered card with header/body
- `variant="compact"`: Inline label + actions, no border

### Files Modified

| File | Action |
|------|--------|
| `shared/primitives.tsx` | Extended TestCard interface |
| `DataGridTestbed.tsx` | Removed duplicate, added `variant="compact"` to 6 usages |
| `EffectAtomTestbed.tsx` | Removed 4 duplicates (SectionLabel, Button, StatusIndicator, CollapsiblePanel) |

### Intentionally Kept Local

- `EffectAtomTestbed.tsx:ValueDisplay` — Uses `JSON.stringify(value)`, different from shared
- `EffectAtomTestbed.tsx:ValidationCard` — Testbed-specific, not promoted to shared
- `VantaCardTestbed.tsx:StatusIndicatorShowcase` — Different component (showcase, not primitive)

## Lessons

1. **Morph on large files**: Can timeout or introduce syntax errors
2. **Regex/sed for JSX**: Never. Surgical Read + Edit only.
3. **Component extraction**: Always audit usages with grep before cutting imports
