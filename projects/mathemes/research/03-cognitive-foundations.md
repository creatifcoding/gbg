# Cognitive Science Foundations

**Status**: Enriched synthesis — grounded in Sweller (1988), Miller (1956), Paivio (1969), Lupyan (2012, 2015), Goldstone et al. (2001), and Lakoff & Núñez (2000).

---

## Thesis

A mathematical name is not a tag attached after understanding. It is part of the cognitive interface by which understanding is built: it consumes or saves working memory, guides attention, creates chunks, activates imagery, shapes category perception, and primes inference. For Mathemes, a good name is a **compressed executable description**: it should help the learner run the concept, not merely point to it.

The evidence is convergent rather than single-source. Sweller shows that cognitive effort spent on goal search can block schema acquisition. Miller shows that language recodes many bits into fewer chunks. Paivio shows that verbal and imagistic systems provide distinct memory routes. Lupyan shows that labels modulate perception and categorization online, including early visual processing within ~100 ms. Goldstone shows that category learning changes object representations themselves. Lakoff and Núñez explain why mathematical thought is especially dependent on embodied metaphorical mappings.

## 1. Cognitive Load: Names Can Either Consume Search or Build Schemas

Sweller's 1988 paper argues that conventional problem solving often produces answers while interfering with learning. The mechanism is **means-ends analysis**: novices compare the current state to a goal state, select operators to reduce the difference, maintain subgoals, and backtrack. This consumes processing capacity that is therefore unavailable for schema acquisition.

The important expert-novice result is that experts possess schemas: structures that let them recognize a problem state as belonging to a class that calls for particular moves. Chess masters recall realistic boards better than novices but not random boards; physics experts categorize problems by principles such as conservation of energy while novices categorize by surface objects; experts work forward because schemas tell them which operators follow from the givens. So an expert may experience “Hausdorff” as one efficient chunk. A novice experiences it as a retrieval problem.

Sweller's computational model makes the load visible. In an equation-chaining kinematics example, the conventional means-ends version and the nonspecific-goal version began with the same 14 working-memory statements. The conventional version then required more processing: average working memory 15.5 and peak 16 versus 14; 4 active productions versus 1; 5 cycles versus 3; and 29 condition matches versus 17. The content was the same. The excess load came from the strategy.

The experimental work strengthens this. Sweller reports Owen and Sweller's trigonometry studies in which conventional-goal students made **four to six times as many mathematical errors per side calculated** as nonspecific-goal students. In Sweller's own 24-student dual-task experiment, primary problem-solving performance did not significantly differ, but memory for problem structure did. Nonspecific-goal students made fewer reproduction errors on structural features: angle-position errors averaged 1.1 versus 2.4, side-value errors 1.3 versus 2.6, side-position errors 1.2 versus 1.6, and solution errors 1.5 versus 3.4; the nonspecific-goal advantage was significant for angle-position, side-value, side-position, and solution errors.

### Mathemes implication

An opaque term creates a miniature means-ends task before automation:

1. Encounter unknown label.
2. Retrieve mapping from label to concept.
3. Recover the relevant structural property.
4. Only then reason mathematically.

A compositional name such as “point-separated space” turns the same moment into schema rehearsal: *point* selects the objects, *separated* selects the relation, and *space* selects the ambient structure. The name is not just a pointer; it is a worked micro-example of what to attend to.

**Non-obvious connection:** Sweller implies that early names should expose available moves, not final honors. “Compact-open topology” tells the learner where to look: compact subsets and open sets. “Hausdorff” does not. But Sweller also predicts an expert-reversal: after automation, compact aliases can be efficient. Mathemes should therefore distinguish **acquisition names** from **expert aliases**.

## 2. Chunking and Recoding: A Name Is a Compression Algorithm

Miller's “magical number seven” paper is not simply “memory holds seven things.” It separates absolute judgment limits from immediate-memory limits and shows how humans evade both by multidimensional coding and recoding.

In absolute judgment, one-dimensional channel capacities are small: pitch asymptotes around 2.5 bits, about six alternatives; loudness around 2.3 bits, about five; salt concentration around 1.9 bits, about four; visual position around 3.25 bits, about ten to fifteen. Adding dimensions helps but subadditively: dot position in a square yielded 4.6 bits, about 24 positions, not the 6.5 bits predicted by perfectly adding two interval judgments. Six-dimensional auditory displays yielded 7.2 bits, about 150 categories.

Immediate memory behaves differently. Hayes found spans of about nine binary digits but about five monosyllabic English words, showing that memory is not holding a constant number of bits. Miller's unit is the **chunk**. Smith's binary recoding demonstration then shows how powerful chunking can be: by grouping binary digits into pairs, triples, quadruples, or quintuples and renaming them, a practiced subject could reproduce about 40 binary digits. Miller emphasizes the catch: recoding must become nearly automatic, or translation itself consumes capacity.

Miller explicitly identifies verbal recoding as central to thought. People remember stories or events by putting them “in our own words,” then reconstruct details consistent with that wording. This is exactly the power and danger of naming.

### Mathemes implication

A name should be judged by **semantic information per active chunk**, not by raw brevity. “Hilbert space” is two words but one opaque person-chunk plus one generic structure-chunk. “Complete inner-product space” is longer but its chunks carry mathematical constraints. It can later compress into one expert chunk.

Names should also be multidimensional. Eponyms distinguish concepts along one irrelevant dimension: discoverer identity. Mathemes should distinguish concepts along mathematical dimensions: algebraic law, topology, variance, order, universal property, boundary behavior, proof role.

**Design rule:** maximize `semantic information / active chunk count`. A good matheme is first parseable compositionally and later compressible automatically.

## 3. Dual Coding and Imagery: Names Should Recruit Nonverbal Structure

Paivio's 1969 review operationally separates imagery and verbal symbolic processes. Imagery was manipulated by varying the image-evoking value of material and by instructing subjects to use imagery as a mediator; verbal processing was manipulated through meaningfulness and verbal-mediator instructions. The program's central result is that learning and memory benefit when material can be encoded through both verbal and nonverbal imagery systems.

The transfer to mathematics is not “draw more pictures.” It is that a mathematical name can provide more than one retrieval route. Opaque names provide a lexical route. Imageable compositional names provide lexical plus spatial, motor, or perceptual routes.

Mathematics already uses these mechanisms: *pullback*, *pushforward*, *fiber*, *cover*, *boundary*, *closure*, *projection*, *orbit*, *flow*, *kernel*. These names are not formal definitions, but they bind formal structures to image schemas that support recall and inference.

### Mathemes implication

Mathemes should prefer **inference-preserving imagery**, not decorative metaphor. “Closure” is good when it evokes adding what is needed until sealed under an operation. “Dense” is good when it evokes no gaps. “Normal” is bad because everyday normality supplies no stable mathematical inference and conflicts across fields.

**Non-obvious connection:** Paivio plus Miller predicts that the strongest names are **dual-coded chunks**: they compress formal constraints while activating a spatial or motor schema. Paivio plus Sweller predicts that such names reduce load by turning decoding into schema construction.

## 4. Labels as Perceptual Priors: Words Change What Learners Notice

Lupyan's work is the strongest evidence that labels are active cognitive tools rather than passive pointers.

### The 2015 ERP evidence

Boutonnet and Lupyan tested 14 English monolingual speakers on 500 cued-picture recognition trials. Participants heard either a word such as “dog” or an equally familiar and unambiguous sound such as a bark, then saw a picture and judged whether it matched. Stimuli included 50 pictures from 10 categories. Sounds were recognizable: participants produced the correct label for them 89% of the time.

Labels improved behavior: reaction times were faster for labels than sounds, b = 10.4, t = 5.4, p < .0001, and accuracy was higher, 97% versus 95%, b = .01, t = 4.5, p < .0001.

The crucial result is electrophysiological. Label-cued pictures elicited a larger P1 than sound-cued pictures, mean difference .45 µV, t = 2.37, p = .02. P1 occurs roughly 70–125 ms after image onset and indexes early visual processing. The N4 semantic-incongruity component was strongly affected by cue-picture congruence, mean difference 1.7 µV, p < .0001, but not by cue type. So words and sounds were semantically comparable later, but words changed earlier visual processing.

Single-trial analyses show that this early modulation mattered. Earlier P1 peaks predicted faster reaction times, b = .23, p = .02; larger P1s also predicted faster RTs, b = .56, p = .01. Cue type interacted with P1 latency in predicting cue-picture congruence, b = .42, t = 3.79, p = .0002. For label-cued trials, P1 properties distinguished matches from mismatches, b = .59, t = 3.8, p = .0002; for sound-cued trials, they did not, p = .12.

### The 2012 label-feedback framework

Lupyan's 2012 review explains why linguistic effects can be both deep and fragile. Words modulate ongoing perception through top-down feedback, but verbal interference can disrupt this modulation. The review cites color-category effects reduced by verbal interference, aphasic categorization impairments, and tasks where redundant labels improve detection and search.

Relevant paradigms include:

- Novel “alien” categories: redundant labels such as “leebish” and “grecious” helped participants learn 16 approach/avoid aliens; equally redundant nonlinguistic cues did not.
- Typicality prompts: the same chair or lamp was rated more typical when the prompt named it (“that chair”) than when it used a generic term (“that object”).
- Triangle studies: even though participants knew triangles are three-sided polygons, the word “triangle” activated canonical triangles more than “three-sided figure,” changing recognition speed and angle estimates.

### Mathemes implication

If “dog” makes people better dog-detectors within ~100 ms, a mathematical name can plausibly make learners better invariant-detectors. “Point-separated” should cue point-pairs and separating neighborhoods. “Finite-subcover” should cue covers and finite extraction. “Kernel-image exactness” should cue the image-equals-kernel relation.

But Lupyan also warns us: labels activate prototypes. “Triangle” biases toward canonical triangles despite the correct formal definition. Therefore Mathemes must avoid labels that create affective prototypes without structural content: *normal*, *regular*, *nice*, *good*, *well-behaved*. Prime, those are not names; they are vibes in a trench coat.

## 5. Category Learning Changes Representations: Nomenclature Trains Perception

Goldstone, Lippa, and Shiffrin (2001) ask whether category learning merely biases judgments or changes object representations themselves. Their design distinguishes **Strategic Judgment Bias** from **Altered Object Description**.

Participants saw morphed bald-face stimuli created from four source faces A–D plus a neutral face E that was never categorized. They first rated similarities, then learned categories over 216 trials, then rated similarities again. Of 193 participants, four failed the learning criterion and were excluded. The critical trick was the neutral face: if category learning only teaches a strategy such as “same label means similar,” it should not systematically change ratings involving an uncategorized neutral object.

Direct ratings between categorized faces showed between-category expansion: faces assigned to different categories were rated less similar after learning, F(1,185) = 5.49, p < .05. Within-category direct similarity did not significantly change. But the indirect neutral-face measure showed representational compression: similarity ratings involving same-category faces and the neutral face became more alike after learning, F(1,185) = 10.51, p < .01; the condition × time interaction was significant, F(1,185) = 5.35, p < .05. The authors conclude that category learning changed object descriptions themselves.

### Mathemes implication

A naming system is an implicit category curriculum. If concepts are grouped by discoverer — Noetherian, Artinian, Hausdorff, Hilbert — the names do not train structural perception. If they are grouped by mathematical dimensions — chain conditions, separation properties, completeness, inner products, compactness, exactness — repeated naming trains attention toward those dimensions.

**Non-obvious connection:** Goldstone plus Lupyan predicts a feedback loop:

1. Label cues attention to features.
2. Attended features become category-relevant.
3. Category learning alters representations.
4. Altered representations make the label feel natural.

This explains expert blindness. After years of representational reshaping, opaque terms feel transparent. Mathemes should accelerate this loop by encoding the feature from the beginning.

## 6. Embodied Metaphor: Mathematical Names Should Preserve Inference

Lakoff and Núñez argue that mathematics is built from human cognitive mechanisms, including embodiment, the cognitive unconscious, and conceptual metaphor. Their examples include numbers as points on a line, classes as algebraic objects, logic as calculation, angles as numbers, multiplication by complex numbers as rotation, and actual infinity as metaphorical completion of endless processes.

For Mathemes, the crucial claim is that mathematical metaphors import **inference patterns** from concrete source domains. “Sets are containers” imports membership, inclusion, emptiness, overlap, and boundary. “Functions are machines” imports input-output transformation and composition. “Numbers are points on a line” imports order, distance, direction, and motion.

### Mathemes implication

Names should be chosen for the inference schemas they recruit. “Pullback” is strong because pulling back along a map preserves directional structure. “Quotient” is strong when it evokes collapsing or identifying. “Lift” is strong when it evokes moving structure to a higher or covering level.

### Limit

Lakoff and Núñez provide a theoretical framework, not a controlled naming experiment. Their work should guide candidate generation and metaphor audits, not settle empirical claims by itself. A metaphor is useful only where it preserves the intended inference; “space-filling curve” can mislead if “filling” is read in ordinary volumetric terms.

## 7. Design Principles for Mathemes

1. **Expose schema structure during acquisition.** Names should identify roles, invariants, or operations, following Sweller's evidence that attention to structure supports schema acquisition.
2. **Optimize information per chunk.** A longer compositional name can be better than a shorter opaque name if its parts are meaningful and later compressible, following Miller.
3. **Use dual-coded morphemes.** Prefer spatial, motor, or perceptual schemas when they preserve inference, following Paivio and Lakoff & Núñez.
4. **Make labels feature cues.** Names should prime what to inspect, following Lupyan's label-feedback and P1 evidence.
5. **Group by structural dimensions.** Naming families should train acquired distinctiveness and equivalence along useful mathematical axes, following Goldstone.
6. **Separate acquisition names from expert aliases.** Opaque short names may be efficient after automation but costly before it.
7. **Audit metaphor failures.** Every metaphorical name needs a “breaks here” note.

## 8. Empirical Predictions

1. **Load prediction.** Learners using Mathemes names should outperform eponym-trained learners on secondary-task recall while primary problem accuracy is matched, adapting Sweller's dual-task design.
2. **Error prediction.** Eponym-trained novices should make more definition-retrieval and operator-selection errors per solved problem. The direction follows Owen and Sweller's four-to-sixfold error finding, though the magnitude must be measured directly.
3. **Chunking prediction.** Mathemes-trained learners should recall more concept-property pairings under immediate-memory limits because the name recodes properties into meaningful chunks, following Miller.
4. **Dual-code prediction.** Image-schema names should improve delayed recall more than equally descriptive but non-imageable paraphrases, especially when learners draw or gesture concepts, following Paivio.
5. **Attention prediction.** Eye-tracking should show earlier fixation on definition-relevant features after Mathemes labels. Example: “point-separated space” should speed inspection of point pairs and neighborhoods relative to “Hausdorff space.”
6. **ERP prediction.** For trained learners, compositional labels should modulate early symbolic or diagrammatic processing more than arbitrary labels, analogous to Boutonnet and Lupyan's label-specific P1 effect.
7. **Category-warping prediction.** After training under Mathemes families, learners should sort novel objects more by name-encoded structural dimensions, adapting Goldstone's neutral-object paradigm.
8. **Metaphor-break prediction.** Metaphorical names should improve near transfer but induce predictable far-transfer errors at metaphor boundaries unless those boundaries are explicitly taught.

---

## Cautions

- Expert fluency is not novice fluency. Experts have automated opaque names into chunks.
- Descriptive names can overload if the component morphemes are not already available.
- Labels can distort by activating prototypes, as Lupyan's triangle findings show.
- Metaphors are contracts, not decorations: they must preserve inference.
- The evidence transfers from adjacent domains; Mathemes still needs direct experiments on mathematical nomenclature.

---

## Final Synthesis

Mathematical nomenclature is cognitive engineering. Names allocate attention, compress information, recruit imagery, train categories, and activate inference. Eponyms can become efficient expert tokens, but they do little for schema formation. Mathemes should be compositional enough to teach, compact enough to chunk, vivid enough to dual-code, and precise enough not to lie.
