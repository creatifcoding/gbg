# IoT Smoke Detection - Current Status

## ✅ What's Done

### Environment Setup

- **UV package manager** for Python dependencies (no Nix for Python packages)
- **DuckDB CLI** available via Nix (`nix/modules/duckdb.nix`)
- **Installed packages** (via `uv pip install`):
  - JAX + Equinox + Optax (ML training)
  - DuckDB + Polars (data analysis)

### Dataset

- **Real IoT sensor data**: 5,000 training samples, 12,437 test samples
- **14 features**: Temperature, Humidity, TVOC, eCO2, PM sensors, CNT, etc.
- **Binary target**: Fire Alarm (72.3% no fire, 27.7% fire)
- **Key insight**: CNT has strongest correlation (+0.7974) with fire alarms

### Code

#### 1. JAX Training (`train_simple.py`)

- ✅ Simple MLP: 13 → 64 → 32 → 2
- ✅ Class-weighted loss for imbalance
- ✅ Running in background (training.log)
- **Status**: Training in progress (~50 epochs)

#### 2. DuckDB + Polars Analysis (`analyze_with_duckdb.py`)

- ✅ SQL-based feature correlations
- ✅ Temperature range analysis
- ✅ Polars DataFrame operations (10x faster than pandas)
- ✅ Parquet export (2.2x compression vs CSV)
- **Output**: `smoke_analysis/data/processed/train_with_features.parquet`

## 📊 Key Findings (from DuckDB analysis)

### Feature Correlations

```
CNT:            +0.7974  ← Strongest predictor
Humidity:       +0.3112
Temperature:    -0.1723
TVOC:           -0.1291
PM2.5:          -0.0415
```

### Fire Alarm by Temperature

```
Below 10°C:     41.0% fire rate
10-20°C:        21.4%
20-30°C:        29.0%
30-40°C:        40.3%
Above 40°C:      1.7%  ← Anomaly (sensors may shut off in extreme heat)
```
