# logs/

Reflection logs tracking session quality and task outcomes.

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `sessions/` | Session-level briefings (start/end summary, overall performance) |
| `tasks/` | Task-level logs (per-feature or per-bug reflection) |

## Format

Each log file uses markdown with:
- Timestamp
- Outcome (success/partial/failure)
- What went well
- What went wrong
- Learnings for next time
