### Critical Bridge

`GeointMap.tsx:401-416` is the **sole bridge** between R2 and R3. `handleViewStateChange` writes to R2 (`setViewState`) then calls `syncViewport` which writes to R3. **R1 is never synced from R2 or R3** — it's updated independently via `MapController` and `mapOperations`.

### Risk: R1 ↔ R3 Drift

`MapController` writes to R1. `positioning/hooks` writes to R3. There is **no sync mechanism** between them. Any component reading R1 will see stale state if R3 is the one being updated, and vice versa.
