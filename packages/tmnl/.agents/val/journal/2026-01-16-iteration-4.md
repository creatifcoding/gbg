## Technical Notes

### Ink Crash in Bun/WSL

```
panic(main thread): Segmentation fault at address 0x1A
error: script "ctl" was terminated by signal SIGILL (Illegal instruction)
```

This is a known limitation when running Bun with Ink in WSL environments. The adapter is available for use in environments that support it.

### Usage Pattern

```typescript
// For environments that support Ink:
import { InkOutputLayer } from "../adapters/output/ink.js"
const layer = InkOutputLayer

// Default (stable):
import { ConsoleOutputLayer } from "../adapters/output/console.js"
const layer = ConsoleOutputLayer
```
