## Architecture Decisions Reinforced

1. **Atomic Validate-and-Execute**: No separate validation API call. Server validates internally, returns results OR errors.

2. **Protobuf-First**: All messages defined in proto, exposed via Cosmo Connect. REST is auto-generated fallback.

3. **Rich Error Location**: `ErrorLocation` enables UI to highlight exact position of errors (channel, pipeline index, field).

4. **Tiered Output Format**: Client chooses JSON (readable) or Arrow IPC (efficient) via `OutputFormat` enum.
