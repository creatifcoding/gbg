Sometimes, you may want to create a new schema based on an existing one,
focusing specifically on either its `Type`{dir="auto"} or
`Encoded`{dir="auto"} aspect. The Schema module provides several
functions to make this possible.

The `Schema.typeSchema`{dir="auto"} function is used to extract the
`Type`{dir="auto"} portion of a schema, resulting in a new schema that
retains only the type-specific properties from the original schema. This
excludes any initial encoding or transformation logic applied to the
original schema.
