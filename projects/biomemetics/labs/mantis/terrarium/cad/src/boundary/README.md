# B20 and keep-out OCCT source

Working draft B. Maturity DRAFT.

B20 is a continuous non-metal structural solid across front and left joints, splices, ends, door, and cassette seats. It is the animal/wet barrier. It is not a film over contacts.

Named keep-outs: animal volume, wet tray, hang-molt upper third, non-metal ceiling screen, nymph door gap TARGET 0.50 mm, door swing, drain envelope UNVERIFIED, PCB/B27/B50 proxy UNVERIFIED.

No animal-side copper, pogo, or metal mesh. Screen aperture stays <= 0.80 mm LOCK.

Nominal SVG/DXF cut profiles for B05/B06 live under `exports/profiles/`. Kerf-compensated files are named with the 0.15 mm REF kerf and the params.json digest. They are not shop-release cut paths.
